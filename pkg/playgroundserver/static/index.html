EMBED

              
A small API between your product and its scripts.

              
Execute source directly, pass application data into the global scope, set per-run context and limits, or keep a reusable runtime for repeated work.

              
  • One-shot and reusable runtime APIs
  • Context cancellation and typed errors
  • Sessions, checkpoints, and replay

            

            

              
host.goGO

              
result, err := interpreter.ExecWithOptions(
    source,
    map[string]any{"order": order},
    interpreter.ExecOptions{
        Profile: "untrusted",
        Context: ctx,
        MaxSteps: 500_000,
    },
)

AUTHOR

              
Readable scripts with enough language to scale.

              
Start with familiar C-family syntax and grow into structured modules, types, matching, concurrency, and reusable abstractions when the work demands it.

              
  • Functions, closures, classes, and interfaces
  • ADTs, pattern matching, macros, and modules
  • Async/await, channels, generators, and streams

            

            

              
Corefunctions · collections · errors

              
Structuremodules · classes · interfaces

              
Modelingtypes · match · destructuring

              
Concurrencyasync · channels · streams

            

          

          

            

              
OPERATE

              
Execution you can observe, stop, and explain.

              
Bound every run, classify failures, surface diagnostics, and connect lifecycle hooks to the logging and metrics systems your team already operates.

              
  • Step, depth, heap, output, and time limits
  • Policy, limit, timeout, and cancellation errors
  • Execution and policy-denial observability hooks

Expose your domain, not your entire process.

              
Register native built-ins and standard modules that match your product model. Scripts see the interface you design—not arbitrary host internals.

              
  • Runtime plugins and custom built-ins
  • Application-specific standard modules
  • Broad built-in data and integration library

02 / WORKLOADS
One runtime. Four practical jobs.

        

          
01
Decision logic
Eligibility, routing, pricing, validation, and approval rules.
input → match → decision

          
02
Data operations
Parse, validate, transform, enrich, query, and export structured data.
JSON · CSV · YAML · DB

          
03
Workflow automation
Coordinate APIs, files, schedules, documents, and operational tasks.
HTTP · files · scheduler

          
04
Product scripting
Offer customer-defined behavior inside boundaries your application owns.
plugin API → safe result
